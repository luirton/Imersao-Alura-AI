# Desafio 2 - Calculadora Web 🧮

Projeto desenvolvido para o **Desafio 2** da **Imersão Alura AI**. Trata-se de uma aplicação web de calculadora moderna, intuitiva e totalmente responsiva.

---

## ✨ Funcionalidades

- **Operações Básicas:** Adição (+), Subtração (−), Multiplicação (×) e Divisão (÷).
- **Operações Especiais:** 
  - Cálculo de porcentagem (`%`)
  - Inversão de sinal positivo/negativo (`±`)
  - Remoção do último dígito (`DEL`)
  - Limpeza total (`AC`)
- **Proteção contra erros:** Tratamento amigável para divisão por zero (`Erro`).
- **Formatação Numérica:** Formato numérico em padrão brasileiro (ex: separação de milhares e vírgula decimal).
- **Suporte a Teclado:**
  - Números `0` a `9` e ponto/vírgula `.`
  - Operadores: `+`, `-`, `*`, `/`
  - Calcular: `Enter` ou `=`
  - Apagar: `Backspace`
  - Limpar: `Escape`
  - Porcentagem: `%`
- **Design Moderno:** Interface com estética escura (dark theme), sombras suaves e efeito glassmorphism.

---

## 🚀 Como Executar

Por ser um projeto web puramente client-side (HTML5, CSS3 e JavaScript Vanilla), não é necessária nenhuma instalação prévia ou dependência de pacotes:

1. Clone o repositório ou baixe os arquivos.
2. Navegue até a pasta `Desafio 2`.
3. Abra o arquivo `index.html` em qualquer navegador web moderno (Chrome, Edge, Firefox, Safari).

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estrutura semântica dos componentes.
- **CSS3:** Estilização moderna com Flexbox, CSS Grid, variáveis e gradientes.
- **JavaScript (ES6+):** Lógica da calculadora estruturada com orientação a objetos (classe `Calculator`).
